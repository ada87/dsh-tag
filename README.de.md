1. Farbige Tags für Sitzungen und Workspaces in DeepSeek Harness.
2. Sitzungen und Workspaces auf der Seite nach Tag filtern.
3. Ungelesene Sitzungen bleiben fett, bis du sie öffnest.

![Filtern nach Tag](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/sidebar.png)

## Installation

Plugins → Plugin hinzufügen → `dsh-tag`

![Plugin hinzufügen](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/install.png)

## Verwendung

- Rechtsklick auf eine Sitzung oder einen Workspace-Kopf → **Tag** → Farbe wählen
- Ein Tag am Workspace deckt die gesamte Gruppe ab
- Klicke auf eine Farbe über der Workspace-Liste, um zu filtern; passende Gruppen öffnen sich mit Anzahl
- Einstellungen → **DSH Tag**: umbenennen, umfärben, löschen, anlegen. Höchstens 10 Tags, jeder mit eigener Farbe

![DSH Tag-Einstellungen](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/settings.png)
