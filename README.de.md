Farbige Tags für Sitzungen und Workspaces in DeepSeek Harness: ein Tag pro Zeile, der Titel übernimmt die Tag-Farbe, und die Leiste über der Workspace-Liste filtert nach Tag.

![Zwei Workspaces mit getaggten Sitzungen und der Filterleiste](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/sidebar.png)

## Installation

Plugins → Plugin hinzufügen → `dsh-tag`

![Plugin hinzufügen](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/install.png)

## Verwendung

- Rechtsklick auf eine Sitzung oder einen Workspace-Kopf → **Tags** → Farbe wählen
- Ein Workspace-Tag deckt die gesamte Gruppe ab
- Klicke auf eine Farbe über der Workspace-Liste, um zu filtern; passende Gruppen öffnen sich mit Anzahl
- Einstellungen → **DSH Tag**: umbenennen, umfärben, löschen, hinzufügen. Bis zu 10 Tags, je eine Farbe
- Die Filterleiste kann ausgeblendet werden, wenn du sie nicht brauchst

![DSH Tag Einstellungen](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/settings.png)
