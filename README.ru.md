1. Цветные метки для сессий и рабочих пространств в DeepSeek Harness.
2. Фильтрация сессий и рабочих пространств на странице по метке.
3. Непрочитанные сессии остаются с жирным заголовком, пока их не откроешь.

![Фильтрация по метке](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/sidebar.png)

## Установка

Плагины → Добавить плагин → `dsh-tag`

![Добавить плагин](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/install.png)

## Использование

- Правый клик по сессии или заголовку рабочего пространства → **Метка** → выберите цвет
- Метка на рабочем пространстве покрывает всю группу
- Нажмите на цвет над списком рабочих пространств, чтобы отфильтровать; подходящие группы раскрываются с количеством
- Настройки → **DSH Tag**: переименовать, сменить цвет, удалить, добавить. Не более 10 меток, у каждой свой цвет

![Настройки DSH Tag](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/settings.png)
