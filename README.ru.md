# DSH Tag

[English](README.md) | [中文](README.zh.md) | [日本語](README.ja.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | Русский | [Português](README.pt.md)

Цветные метки для сессий и рабочих пространств DeepSeek Harness: одна метка на строку, заголовок окрашивается в её цвет, а полоса над списком рабочих пространств фильтрует по метке.

![Два рабочих пространства с помеченными сессиями и панелью фильтров](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/sidebar.png)

## Установка

Плагины → Добавить плагин → `dsh-tag@0.1.1`

![Добавить плагин](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/install.png)

## Использование

- Правый клик по сессии или заголовку рабочего пространства → **Метки** → выберите цвет
- Метка рабочего пространства покрывает всю группу
- Нажмите на цвет над списком рабочих пространств, чтобы отфильтровать; подходящие группы откроются с количеством
- Настройки → **DSH Tag**: переименовать, сменить цвет, удалить, добавить. До 10 меток, по одному цвету на каждую
- Панель фильтров можно отключить, если она не нужна

![Настройки DSH Tag](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/settings.png)

API, цвета, совместимость и разработка: [docs/REFERENCE.md](https://github.com/ada87/dsh-tag/blob/main/docs/REFERENCE.md).
