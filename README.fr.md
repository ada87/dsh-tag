1. Des étiquettes de couleur pour les sessions et les espaces de travail de DeepSeek Harness.
2. Filtrez par étiquette les sessions et les espaces de travail affichés.
3. Les sessions non lues gardent un titre en gras jusqu’à leur ouverture.

![Filtrage par étiquette](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/sidebar.png)

## Installation

Extensions → Ajouter une extension → `dsh-tag`

![Ajouter une extension](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/install.png)

## Utilisation

- Clic droit sur une session ou sur l’en-tête d’un espace de travail → **Étiquette** → choisissez une couleur
- Une étiquette posée sur un espace de travail couvre tout le groupe
- Cliquez sur une couleur au-dessus de la liste des espaces de travail pour filtrer ; les groupes concernés s’ouvrent avec leur nombre
- Réglages → **DSH Tag** : renommer, changer de couleur, supprimer, ajouter. Jusqu’à 10 étiquettes, une couleur chacune

![Réglages de DSH Tag](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/settings.png)
