Étiquettes de couleur pour les sessions et espaces de travail de DeepSeek Harness : une étiquette par ligne, le titre prend sa couleur et la barre au-dessus de la liste des espaces de travail filtre par étiquette.

![Deux espaces de travail avec des sessions étiquetées et la barre de filtres](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/sidebar.png)

## Installation

Extensions → Ajouter une extension → `dsh-tag`

![Ajouter une extension](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/install.png)

## Utilisation

- Clic droit sur une session ou l’en-tête d’un espace de travail → **Étiquettes** → choisissez une couleur
- L’étiquette d’un espace de travail couvre tout le groupe
- Cliquez sur une couleur au-dessus de la liste pour filtrer ; les groupes correspondants s’ouvrent avec leur nombre
- Réglages → **DSH Tag** : renommer, changer la couleur, supprimer, ajouter. Jusqu’à 10 étiquettes, une couleur chacune
- Désactivez la barre de filtres si vous ne l’utilisez pas

![Réglages de DSH Tag](https://raw.githubusercontent.com/ada87/dsh-tag/main/docs/images/settings.png)
